## Added

- Product vision document defining Solo as a fully on-device, proactive, autonomous AI agent for Android and iOS
- Technical feasibility validation against 2025-2026 state-of-the-art: on-device LLMs, vector databases, app automation, voice pipelines, and health data access
- System architecture design including the Reasoning Engine, Behavior Model, Skill Registry, Personal Knowledge Graph, and Episodic Memory Store
- Hibernation architecture for battery-efficient background execution inspired by the Jagarin three-layer model
- Confidence and autonomy framework for calibrated autonomous action — from silent action at high confidence to passive observation at low confidence
- Privacy enforcement architecture with zero data upload as an architectural constraint, not a setting
- Novel research agenda covering six frontier problems: Autonomous App Skill Generation, Individual Behavior Modeling, Confidence-Calibrated Action, Cross-App Semantic Unification, Long-Term Memory Consolidation, and Emotion-Aware Interaction
- Open-source distribution model via GitHub with sideload-first installation for both Android and iOS
- Project website with changelog, contribution pathways, and development status
